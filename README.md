# Личен седмичен планер (с облачна синхронизация)

Планер със задачи по часови слотове, бележки, линкове, напомняния и тефтерче.
Данните се пазят в Supabase (безплатна облачна база) и се синхронизират
между всички устройства, на които влезеш с твоя имейл и парола.

Сайт: https://bydimitrova-cloud.github.io/weekly-planner/

## Възможности

- Седмичен календар с часови слотове (07:00–20:00) и бележки за уикенда
- Отбелязване на ден като работен или неработен
- Бърз избор на година и месец
- Напомняния („Да не забравя!“), бързи бележки и полезни линкове
- „Моето тефтерче“: лични записи с търсене по ключова дума
- Мисъл за деня (от `quotes.json`), часовник и онлайн радио
- 5 теми: Сакура, Морска, Фън шуй, Звездна нощ и Домино
- Начален екран с видео фон и анимирано заглавие
- Мобилна версия (дните се разгъват като акордеон) и версия за печат

## Как работи

- При отваряне на сайта се показва началният екран; бутонът „Вход за
  потребители“ отваря формата за вход.
- Регистрираш се с имейл + парола (Supabase изпраща имейл за потвърждение —
  провери пощата си след регистрация).
- След вход всичко, което пишеш, автоматично се качва в облака.
- Отваряш сайта на друго устройство, влизаш със същия имейл/парола —
  данните са там.

## Supabase настройка (вече направена)

- Таблица `planner_data` с колони: `id`, `created_at`, `data` (jsonb), `user_id` (uuid)
- Row Level Security включено — всеки вижда само собствените си редове
- Policies: select / insert / update само където `auth.uid() = user_id`
- Уникален индекс по `user_id`, за да работи upsert:
  ```sql
  alter table planner_data
  add constraint planner_data_user_id_unique unique (user_id);
  ```

## Локално стартиране

Препоръчително е да се отвори чрез Live Server във VS Code (бутон „Go Live“).
Ако `index.html` се отвори директно като файл, браузърите блокират зареждането
на `quotes.json` и се показват само резервните мисли. Изисква интернет връзка
(данните живеят в Supabase, не само локално).

Няма билд стъпка.

## Публикуване

Сайтът се публикува с GitHub Pages от клон `main`. Всеки commit, качен в
GitHub, се появява на живо след 1–2 минути.
